# Nonprofit Decision Framework

This project helps nonprofits make better decisions using public data.

## Main Decisions the Toolkit Should Support

1. Where should the nonprofit focus outreach?
2. Which communities best match the nonprofit's mission?
3. What demographic patterns matter in each area?
4. What barriers might affect outreach?
5. What communication strategy should be used?
6. What partnerships may be useful?
7. What data evidence supports the final marketing and business strategy?

## Data Categories Needed

### Demographic Data
- Total population
- Youth population
- Age groups
- Race and ethnicity
- Household composition

### Socioeconomic Data
- Median household income
- Poverty rate
- Unemployment rate
- Education level
- Broadband internet access

### Geographic Data
- County boundaries
- Census tract boundaries
- Regional location data

## Final Purpose

The data should support outreach strategy, marketing blueprints, financial planning, and nonprofit growth decisions.
